### 🏠 Stayzen79 — Student Living Ecosystem

**The all-in-one platform for college students in India**

</div>

> Stayzen79 solves the fragmented student housing problem in India — one platform for PG accommodation, food, transport, and daily essentials. Targeting college students in Punjab with plans for a city-by-city national rollout.

| Layer | Tech |
|-------|------|
| 🎨 Frontend | Next.js 14 App Router + Tailwind CSS |
| 🔐 Auth | NextAuth (Google + Credentials) |
| 🗄️ Database | MongoDB + Mongoose (6 collections) |
| 💳 Payments | Razorpay + UPI |
| 📍 Maps | Google Maps API |
| 📲 Notifications | Firebase FCM + SendGrid |

**`PG Listings`** · **`Verified Badges`** · **`UPI Payments`** · **`Real-time Alerts`** · **`Admin Panel`**
